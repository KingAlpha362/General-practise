# Python Input & Loop Practice

Short console exercises for accumulating totals and working with repeated user input.

## ✨ Highlights

- `Question2.py` totals four items and calculates change.
- `form.py` includes weekly fruit totals and another shopping exercise.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "Question2.py"
```

Follow the prompts in the terminal.
